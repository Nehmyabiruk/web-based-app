# neh🌿 Spiritual Tracker App

A beautifully designed spiritual growth companion app built with React and TypeScript.
This app helps users stay consistent in their spiritual journey by tracking daily devotions, prayers, sermons, and reflections.

✨ Features

📖 Daily Devotion Tracking – record and revisit your scripture readings.

🙏 Prayer Requests – write, save, and update personal prayer notes.

🎧 Sermon Log – track sermons and insights for future reference.

🕊 Spiritual Goals – monitor consistency and progress over time.

🌙 Minimal, clean UI with a focus on reflection and focus.

🛠 Tech Stack

⚛️ React – component-based UI

📝 TypeScript – type-safe codebase

🎨 Tailwind CSS / CSS Modules – styling for a clean design

🔄 React Router – smooth navigation across pages

📦 Node.js & npm/yarn – package management

🚀 Getting Started

Clone the repo and run locally:

git clone https://github.com/yourusername/spiritual-tracker.git
cd spiritual-tracker
npm install
npm start
